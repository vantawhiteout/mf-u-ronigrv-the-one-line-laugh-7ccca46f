A single sentence, written to `/output/entry.txt` for make.fun's The One-Line Laugh bounty: one short line with a turn at the end.

## Run it

```sh
node main.ts
```

The entrypoint checks the line is 1–200 non-whitespace UTF-8 characters, creates `/output` if needed, and writes exactly that line, with no trailing newline.
